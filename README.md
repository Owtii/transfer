# transfer

## new template - volledig project

De zip is 5,31 GB. GitHub staat maximaal 2 GB per bestand toe, dus hij staat in 3 delen onder [Releases](https://github.com/Owtii/transfer/releases/tag/new-template-2026-11-07).

1. Download de 3 delen naar dezelfde map.
2. Zet ze weer in elkaar. Open met 7-Zip het bestand dat op `.001` eindigt, of voer in die map in de Opdrachtprompt (cmd) uit:

   ```
   copy /b "new-template-volledig-project.zip.001"+"new-template-volledig-project.zip.002"+"new-template-volledig-project.zip.003" "new template - volledig project.zip"
   ```

3. Controleer de zip (optioneel):

   ```
   certutil -hashfile "new template - volledig project.zip" SHA256
   ```

   De uitkomst moet zijn: `bc7e971cb9299cc47e4c57adcaabe3b450a90a058726039b9a95ace360488d96`
